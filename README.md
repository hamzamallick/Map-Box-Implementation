# 🗺️ Mapbox Implementation

A simple Android project to learn and implement **Mapbox Maps** using **Kotlin** and **Jetpack Compose**.

## ✨ Features

* Mapbox Map integration
* Jetpack Compose
* Navigation Compose
* Home Screen
* Map Screen
* Map zoom and camera position
* Scale Bar
* Mapbox Logo
* Map Attribution
* Back button handling
* Double back press to exit with Toast

## 🛠️ Technologies Used

* Kotlin
* Android
* Jetpack Compose
* Material 3
* Navigation Compose
* Mapbox Maps SDK

## 📱 App Flow

```text
Home Screen
     ↓
Click Open Map
     ↓
Map Screen
     ↓
Press Back
     ↓
Toast Message
     ↓
Press Back Again
     ↓
Exit App
```

## 📂 Project Structure

```text
MainActivity.kt
HomeScreen.kt
MapScreen.kt
```

## 📚 What I Learned

* How to integrate Mapbox in Android
* How to display a map using Jetpack Compose
* How to use Navigation Compose
* How to create separate screens
* How to configure map camera and zoom
* How to handle the Android back button
* How to use `LaunchedEffect`
